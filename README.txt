ROLEPLAY SITE — STARTER PACKAGE

Содержимое:
- public/index.html — интерфейс сайта (создание отдельных сюжетов, локальное сохранение, редактирование сообщений, повтор ответа).
- worker.js — серверный обработчик для Gemini API. Он не работает, пока не будет установлен в Cloudflare Worker и не добавлен секрет GEMINI_API_KEY.
- wrangler.toml — пример конфигурации для Cloudflare Workers Static Assets.

ВАЖНО:
1. Сейчас это стартовый проект, а не уже опубликованный полноценный сайт.
2. Для ИИ нужен отдельный API-ключ. Не отправляйте его в чат и не помещайте в HTML. Добавляйте его в Cloudflare как Secret с именем GEMINI_API_KEY.
3. Бесплатные лимиты API могут меняться; бесконечная бесплатная работа не гарантируется.
4. История в этой стартовой версии хранится в браузере устройства. Синхронизации между телефоном и ноутбуком пока нет.
5. В worker.js используется Gemini 2.5 Flash. Доступность модели и квоты проверьте в аккаунте Google AI Studio.

Дальнейшая публикация:
Для полноценного развертывания потребуется настроить Worker с Static Assets и секретом GEMINI_API_KEY. Не загружайте этот архив в случайные сайты и не делитесь API-ключом..
